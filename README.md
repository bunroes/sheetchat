# sheetchat

스프레드시트처럼 보이는 친구 채팅방.

## 실행
```
npm install
npm start        # http://localhost:3000
```

## 사용법
- 처음 들어가면 이름과 색을 정합니다 (오른쪽 위 동그라미를 누르면 다시 바꿀 수 있어요).
- 위쪽 `fx` 칸에 입력하고 Enter → 메시지 전송
- 사이트 기본 주소로 들어오면 모두 같은 기본 시트(첫 번째 탭)에 모임
- 아래쪽 시트 탭 = 채팅방. `+` 로 새 방 만들기, 탭에 마우스를 올리고 ✕ 로 목록에서 빼기
- 문서 제목을 고치면 방 이름이 바뀝니다 (참여한 모든 사람에게 반영)
- `공유` → 링크 복사 → 친구에게 보내면 초대 완료
- `Esc` → 메시지를 숨기고 영단어장을 보여줌. 다시 누르면 돌아옴
- 새 메시지가 오면 시트 탭에 빨간 숫자, 브라우저 탭 제목에 (숫자)와 빨간 점이 뜸
- 이름 설정 창에서 "새 메시지 알림 받기"를 켜면 다른 창을 보고 있을 때 알림이 옴 (내용은 숨김)
- 메시지 보관 기간은 `공유` 창에서 시트마다 고름: 48시간(기본) / 7일 / 30일 / 계속 보관

## 배포 (친구들이 접속하려면)
Render에 Blueprint로 올리면 `render.yaml` 설정대로 배포됩니다 (시작 명령 `npm run dkwkdkwk`).

### 대화가 사라지지 않게 하기
Render 무료 서버는 잠들거나 재시작할 때 파일이 초기화되므로, `data.json`에 저장된 대화가 지워집니다.
무료 Postgres(예: [Neon](https://neon.tech))를 만들고 그 연결 주소를 Render 서비스의
Environment에 `DATABASE_URL`로 넣으면, 대화가 데이터베이스에 저장되어 재시작해도 남습니다.
`DATABASE_URL`이 없으면 예전처럼 `data.json`을 씁니다.
