# sheetchat

스프레드시트처럼 보이는 친구 채팅방.

## 실행
```
npm install
npm start        # http://localhost:3000
```

## 사용법
- 처음 들어가면 이름과 색을 정합니다 (오른쪽 위 동그라미를 누르면 다시 바꿀 수 있어요).
- 위쪽 `fx` 칸에 입력하고 Enter → 메시지 전송
- 아래쪽 시트 탭 = 채팅방. `+` 로 새 방 만들기, 탭에 마우스를 올리고 ✕ 로 목록에서 빼기
- 문서 제목을 고치면 방 이름이 바뀝니다 (참여한 모든 사람에게 반영)
- `공유` → 링크 복사 → 친구에게 보내면 초대 완료
- `Esc` → 메시지를 숨기고 영단어장을 보여줌. 다시 누르면 돌아옴
- 새 메시지가 오면 시트 탭에 빨간 숫자, 브라우저 탭 제목에 (숫자)와 빨간 점이 뜸
- 이름 설정 창에서 "새 메시지 알림 받기"를 켜면 다른 창을 보고 있을 때 알림이 옴 (내용은 숨김)
- 메시지는 48시간 뒤 자동으로 지워짐 (`server.js`의 `TTL_MS`)

## 배포 (친구들이 접속하려면)
Render / Railway / Fly.io 같은 곳에 이 폴더를 올리면 됩니다. 시작 명령은 `npm start`.
데이터는 `data.json` 파일에 저장되므로, 무료 플랜처럼 재시작 시 디스크가 초기화되는 곳에선
남아 있던 대화가 사라질 수 있습니다 (어차피 48시간이면 지워지긴 해요).
